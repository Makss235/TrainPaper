# TrainPaper

Живые обои с онлайн-табло РЖД — железнодорожная версия Flypaper. Вместо хвоста самолёта
с ливреей авиакомпании — хвостовой вагон поезда РЖД в корпоративной ливрее, вместо ближайшего
самолёта — поезд, который сейчас прибывает на выбранную станцию или отправляется с неё.
Небо, свет и фонари зависят от положения солнца над этой станцией: рассвет, день, закат, ночь.

Чистые HTML, CSS и JS без сборки; сервер — Python только на стандартной библиотеке.

## Два вида

| | |
|---|---|
| **Вагон** — `public/flat/` | Плоская иллюстрация: смотрим с платформы на хвост поезда сбоку. Маршрут и номер — на табличке в окне служебного купе (как настоящая маршрутная доска), слева — табличка станции «Название / латиница / платформа», слева вверху — панель с прибытием/отправлением, путём, опозданием и следующими поездами. |
| **Платформа** — `public/platform/` | 3D-сцена (WebGL, three.js) в стилизованном минимализме: плоские грани в 2–3 тона (cel-shading), мягкие тени от солнца, дымка. Стоим на платформе, справа — хвост поезда (вагоны ФПК, двухэтажные, электропоезд — по номеру поезда), путь уходит к горизонту, контактная сеть, фонари, деревья; над платформой — светодиодное табло. Живые облака и погода (ясно, облачно, пасмурно, дождь, снег, туман). У станций может быть своя сцена (Санкт-Петербург-Главный, Мурманск), сцены описываются в коде как блокаут. Подробно — [`public/assets/js/platform/README.md`](public/assets/js/platform/README.md). |

Оба вида независимы (свой HTML, CSS и `main.js`) и пользуются общими модулями из `assets/js/lib/`.
Если какой-то вид не нужен, достаточно удалить его папку и его файлы в `assets/css` и `assets/js`.

## Запуск

Нужен Python 3.10+. Зависимостей нет, виртуальное окружение не обязательно:

```
python server/run.py              # http://localhost:8000
```

Откройте `http://localhost:8000/` (выбор вида), `…/flat/` или `…/platform/`.
Адрес и порт меняются переменными окружения `HOST` и `PORT`.
Можно установить пакетом: `python -m pip install -e "./server[dev]"`, затем `python -m trainpaper`.

Без сервера (или если открыть страницы любым статическим сервером) обои работают в демо-режиме:
расписание выдумано, в углу горит метка «демо». Скрипты — ES-модули, поэтому открывать
нужно через HTTP, а не двойным щелчком по файлу.

## Настройки

Кнопка с названием станции в правом верхнем углу открывает панель:

- **станция** — популярные вокзалы из списка и поиск по всем станциям РЖД;
- **поезда** — все / только прибытие / только отправление, пригородные (по умолчанию выключены:
  ливрея — вагона дальнего следования);
- **время суток** — авто (по солнцу над станцией), предпросмотр рассвета, дня, заката, ночи
  и «сутки за минуту»;
- **погода** («Платформа») — ясно, переменно, облачно, пасмурно, дождь, снег, туман;
- **сцена** («Платформа») — по станции или любая из готовых;
- **ракурс** («Платформа») — ракурсы камеры, заданные в сцене;
- **вид** — переключение между «Вагоном» и «Платформой».

Настройки хранятся в браузере. Параметры адреса важнее сохранённых:
`?station=1146` (ID станции), `?tod=auto|dawn|day|dusk|night|cycle`,
`?filter=all|arrivals|departures`, `?suburban=1`, `?anim=0` (без анимации — для скриншотов).
Для «Платформы» ещё: `?weather=clear|partly|cloudy|overcast|rain|snow|fog`, `?scene=typical|spb-glavny|murmansk`,
`?cam=main|wide|…` (ракурс), `?train=fpk-long|fpk-double|emu-fast|freight` (показать этот состав),
`?dev=1` (инструмент для сборки сцены: свободная камера, копирование ракурса, сетка, счётчики кадров).

## Как это устроено

### Данные РЖД

Сервер обращается к тем же адресам, что и страница [«Онлайн-табло вокзалов»](https://www.rzd.ru/ru/11497):

| Адрес rzd.ru | Что даёт |
|---|---|
| `/ru/page/77731?id=<ID>&date=ДД.ММ.ГГГГ` | табло станции за сутки (JSON `TABLO.TABLO_TRAIN`) |
| `/suggests/wo-ss-stations/?namePart=<2 буквы>` | поиск станций с внутренними ID табло |
| `/routemap/source/current/train/<номер лат.>/departure/<ГГГГ-ММ-ДД>` | остановки поезда с координатами |

Особенности, которые пришлось учесть (`server/src/trainpaper/board.py`):

- прибытие это или отправление, видно по маршруту: поезд начинает путь на станции — отправление,
  заканчивает — прибытие, иначе транзит (есть и прибытие, и отправление);
- `TRAIN_MOTION_STATUS_NAME` — живой статус: `UNDEF`, `WAITING` (в пути), `COMMING` (ожидается
  прибытие), `IN` (прибыл), `DEPARTING` (ожидается отправление), `OUT` (отправлен);
- время `*_MSK` — московское, `DIFF_TIME_MSK_LOCAL` — разница местного времени с МСК в часах;
- фактическое время появляется после события; до него ожидаемое = план + текущее опоздание;
- платформу и путь РЖД назначает незадолго до прибытия, до этого их нет;
- в табло нет координат станции — их даёт виджет «Поезд на карте» (`geo.py`): берём поезд с табло,
  находим станцию среди его остановок (первая, последняя или по времени и названию)
  и сохраняем в `server/data/geo-cache.json`. Для популярных вокзалов координаты уже лежат
  в `public/assets/data/stations.json`.

**Сертификат.** rzd.ru подписан «Russian Trusted Root CA» Минцифры, которого нет в Windows
и в certifi. Корневой и промежуточный сертификаты (с gu-st.ru) лежат в
`server/src/trainpaper/certs/` и добавляются к системным только для запросов к РЖД —
проверку TLS сервер не отключает. Со стандартным `User-Agent: Python-urllib` rzd.ru отвечает 403,
поэтому сервер представляется как `TrainPaper/0.1`.

Табло станции запрашивается не чаще раза в минуту (сегодня и завтра по местному времени),
поиск станций кэшируется на сутки. Если РЖД не отвечает, полчаса отдаются последние данные.

### API сервера

- `GET /api/board?station=428[&suburban=1]` — станция (`name`, `utcOffset`, `lat`, `lon`) и поезда
  на ближайшие 30 часов: `kind` (arrival/departure/transit), `number`, `numberChange`, `from`, `to`,
  `arrival`/`departure` (`plan`, `actual`, `expected`, секунды Unix), `platform`, `track`, `status`,
  `delay`, `position`.
- `GET /api/stations?q=твер` — станции РЖД по началу названия.

**Ливрея.** Вагон описан один раз в `coach.js` по официальной схеме окраски пассажирского
вагона ФПК (размеры сняты с чертежа в масштабе: длина кузова 7,92 высоты боковины, 25,5 м).
Светло-серый кузов, бордовая линия над тёмно-серым гофрированным низом, 13 окон с тёмной
верхней частью. У одного торца — огромный логотип «РЖД» (векторный путь с rzd.ru), ножкой «Р»
служит красная дверь тамбура; у другого — тёмно-серый тамбур за красной косой полосой с белым
кантом; на простенке в середине — малый логотип и «ФПК». «Вагон» рисует эти фигуры в SVG,
«Платформа» рисует из них текстуру борта и натягивает её на объёмный кузов: борт вертикальный,
дверь прямая на всю высоту, верх скругляется гранями разного тона, окна — настоящие проёмы
со стеклом, утопленным относительно рамы, и откосами; маршрутная табличка стоит в окне каждого вагона.

**Время суток.** Положение солнца считается по координатам станции (формулы NOAA), луна —
библиотекой SunCalc. Небо и солнце обновляются каждый кадр, пока они движутся; смена режима
предпросмотра идёт плавным «прокручиванием» времени (с дня на ночь — через закат).
Все цвета сцены — CSS-переменные: дневной цвет материала × освещённость по высоте солнца.
Днём у каждой группы поверхностей (борт вагона, крыша, пол, предметы лицом к зрителю) своя
освещённость от направления на солнце: теневая сторона холоднее, освещённая — теплее.
В «Платформе» тон каждой грани — рассеянный свет неба плюс солнце по углу к грани (cel-shading),
тени — карта теней от солнца с мягким краем, ограда отбрасывает тень узором. Сила прямого света
плавно растёт от −1,5° до +3,5° высоты солнца, поэтому тени проявляются на рассвете и гаснут
на закате постепенно. Облака — два яруса (кучевые и перистые) из шума, в два тона, их форма
медленно меняется. Погода меняет небо, свет, дымку и добавляет дождь или снег.
В «Вагоне» тени считаются по геометрии сцены (`lib/shadow.js`), облака — `lib/clouds.js`.
Дальние планы уходят в дымку; ночью включаются фонари, свет в окнах, хвостовые огни и подсветка табло.

**Поезд у платформы.** Показывается ближайшее событие: прибывший поезд — ещё 10 минут,
отправляющийся — до минуты после отправления. Когда поезд меняется, текущий уезжает
(разгон), а следующий подходит и тормозит у платформы. В «Платформе» новый поезд появляется
у горизонта электровозом вперёд, проходит мимо и останавливается хвостом у платформы (≈21 с);
на тупиковых вокзалах отправляющиеся поезда стоят локомотивом к выходу и уходят к горизонту.
Какой состав показать, решают правила по номеру поезда (`platform/trains/index.js`): 7xx/8xx —
скоростной электропоезд, некоторые номера — двухэтажный, остальные — вагоны ФПК с электровозом.
При загрузке страницы поезд уже стоит, а сцена плавно проявляется.

**Нагрузка в простое.** «Платформа» рисует кадр, только когда что-то изменилось. Когда поезд стоит,
перерисовывается одно небо с облаками — около 12 раз в секунду в половинном разрешении; сцена и тени
не перерисовываются вовсе. Бегущая строка табло сдвигается шагами в один светодиод, а не каждый кадр.
Если облака не нужны, `STYLE.quality.skyFps = 0` в `platform/style.js` — и в простое не рисуется ничего.
