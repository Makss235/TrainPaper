## Оси и единицы

- Единицы — **метры**. Углы — **градусы**.
- `x` — вправо, `y` — вверх, `z` — к зрителю. Камера по умолчанию смотрит в сторону **−z**.
- Поворот `[x, y, z]` применяется в порядке **Y, X, Z** (сначала поворот вокруг вертикали — удобно
  для «повернуть здание фасадом к путям»).
- Цвет — `"#rrggbb"`, массив `[r, g, b]` (0…1) или **имя из палитры** (`"platform"`, `"steel"`;
  палитра — в `assets/models/index.jsonc`).
- В TrainPaper: `y = 0` — головка рельса, пол платформы — `y = 1,1`; пути идут вдоль `z`.

## Объект

Объект сцены (`GameObject`) в данных:

```jsonc
{
  "name": "Фонарь",                     // имя: по нему ищут (engine.find("Фонарь")) и видят в инспекторе
  "prefab": "lamp",                     // необязательно: основа из assets/prefabs/lamp.jsonc
  "position": [-3.56, 1.1, -14],        // м, относительно родителя
  "rotation": [0, 90, 0],               // °, порядок YXZ
  "scale": 1,                           // число или [x, y, z]
  "tags": ["lamp"],                     // метки: engine.scene.findByTag("lamp")
  "active": true,                       // false — объект выключен (не виден, компоненты спят)
  "static": true,                       // неподвижный → его меши склеиваются (быстрее). Для движущихся — false
  "components": [ { "type": "Model", "model": "station/lamp-post" } ],
  "children": [ { "name": "Ореол", "position": [1, 4.9, 0], "components": [ { "type": "Glow" } ] } ],
  "repeat": { "count": 8, "step": [0, 0, -24] }   // копии со сдвигом
}
```

Все поля необязательны. Пустой объект `{ "name": "Группа", "children": [...] }` — просто узел для
группировки: подвинете его — подвинутся все дети.

Компонент в данных — `{ "type": "ИмяТипа", ...свойства }`. Неизвестное свойство не ломает сцену:
в консоли будет предупреждение со списком правильных имён.

## Префабы

Префаб — объект в файле `assets/prefabs/<имя>.jsonc`. В сцене на него ссылаются и переопределяют что нужно:

```jsonc
// assets/prefabs/lamp.jsonc
{
  "name": "Фонарь",
  "components": [
    { "type": "Model", "model": "station/lamp-post", "params": { "height": 5.2, "arm": 0.9 } },
    { "type": "Light", "range": 11, "intensity": 1.15, "offset": [1.0, 4.7, 0] },
    { "type": "Glow", "radius": 1.7, "color": "#ffebbd", "offset": [1.0, 4.98, 0] }
  ]
}
```

```jsonc
// в сцене
{ "prefab": "lamp", "position": [-4.6, 1.1, -52],
  "components": [
    { "type": "Model", "params": { "height": 4.8 } },      // слияние: у Model поменяется только height
    { "type": "Glow", "remove": true },                    // убрать компонент префаба
    { "type": "Sprite", "texture": "img/sign.png" }        // добавить новый
  ] }
```

Правила слияния:

- поля объекта (`name`, `position`…) из сцены **заменяют** поля префаба;
- компонент с тем же `type` **сливается** по свойствам (глубоко: `params` сливаются по ключам);
  если на объекте два компонента одного типа, различайте их полем `"id"`;
- `{ "type": "…", "remove": true }` убирает компонент префаба;
- `children` префаба и экземпляра складываются.

Готовые префабы TrainPaper: `lamp` (фонарь), `canopy-lamp` (светильник под навесом), `departure-board`
(табло РЖД), `fence` (ограда с тенью-узором), `bench` (скамейка из glTF).

## Повторы (`repeat`)

```jsonc
{ "name": "Деревья", "position": [-16, -0.32, -40],
  "repeat": { "count": 66, "step": [0, 0, -7], "jitter": [4, 0, 2], "scaleJitter": 0.3, "seed": 29 },
  "components": [{ "type": "Model", "model": "environment/tree" }] }
```

| Поле | Что делает |
|---|---|
| `count` | сколько копий |
| `step` | сдвиг каждой следующей копии `[x, y, z]`, м |
| `rotate` | доворот каждой следующей копии `[x, y, z]`, ° |
| `jitter` | случайный сдвиг ± `[x, y, z]`, м |
| `scaleJitter` | случайный масштаб ± доля (0,3 → от 0,7 до 1,3) |
| `randomRotate` | случайный поворот ± `[x, y, z]`, ° |
| `seed` | зерно случайности: одно и то же зерно — та же расстановка |
| `name` | шаблон имени: `"Фонарь {i}"` (по умолчанию «Имя 1», «Имя 2»…) |

Копии — обычные объекты (их видно в инспекторе), но рисуются одним instanced-мешем.

## Объекты из кода

```js
import { GameObject } from "/engine/index.js";

// данными — как в файле сцены
const lamp = await engine.instantiate({ prefab: "lamp", position: [-3.5, 1.1, -30] });
const kiosk = await engine.instantiate({
  name: "Киоск", position: [-3, 1.1, -40],
  components: [{ type: "Primitive", size: [2, 2.5, 3], pivot: "bottom", color: "#c9c2b3" }],
});

// или по шагам
const box = new GameObject("Ящик").setPosition(0, 1.1, -10).setRotation(0, 30, 0);
box.addComponent("Primitive", { size: [1, 1, 1], pivot: "bottom", color: "steel" });
engine.scene.add(box);

// поиск и изменение
const board = engine.find("Табло");                 // по имени; путь — "Навес 1/Светильник 3"
board.getComponent("Light").set({ range: 14 });       // set() проверяет значения и перерисовывает кадр
board.setPosition(0, 1.1, -12);                      // трансформ: setPosition / setRotation (°) / setScale
board.setActive(false);                              // выключить
board.destroy();                                     // удалить

engine.scene.findByTag("lamp");                      // по тегу
engine.scene.components("Light");                    // все компоненты типа
JSON.stringify(board);                               // объект → данные для файла сцены
```

Если вы меняете `object3D` напрямую (через three.js), вызовите `go.moved()` (для склейки и теней)
или хотя бы `engine.invalidate("scene")`.

## Компоненты внешнего вида

Меши компонента лежат внутри `object3D` объекта и двигаются вместе с ним. У всех, кроме
`Sprite`, `Line` и `Glow`, есть общие свойства:

| Свойство | Тип | По умолчанию | Что |
|---|---|---|---|
| `offset` | vec3 | `[0, 0, 0]` | сдвиг внутри объекта, м |
| `rotation` | vec3 | `[0, 0, 0]` | дополнительный поворот внутри объекта, ° |
| `castShadow` | boolean | `true` | отбрасывает тень от солнца (землю, платформу ставьте `false`) |
| `surface` | boolean | `true` | крыша для осадков: под ним нет дождя и снега, пол под ним сухой и без снега |

### `Primitive` — простая фигура

Коробка, цилиндр, конус, сфера или плоскость. Для заготовок (блокаута) и простых деталей прямо в сцене,
без файла модели.

| Свойство | Тип | По умолчанию | Что |
|---|---|---|---|
| `shape` | enum | `"box"` | `box`, `cylinder`, `cone`, `sphere`, `plane` |
| `size` | vec3 | `[1, 1, 1]` | размер `[x, y, z]`, м. У цилиндра и конуса `x` и `z` — диаметры; у плоскости — `[x, —, z]` |
| `pivot` | enum | `"center"` | точка объекта: центр фигуры или `bottom` — середина низа (удобно ставить на пол) |
| `color` | color | `"#cccccc"` | цвет |
| `material` | object | `{}` | параметры материала (см. [ниже](#параметры-материала)) |
| `segments` | number | `0` | грани цилиндра/конуса или подробность сферы (0 — по умолчанию) |

```jsonc
{ "name": "Киоск", "position": [-3, 1.1, -30],
  "components": [
    { "type": "Primitive", "size": [2, 2.5, 3], "pivot": "bottom", "color": "wall" },
    { "type": "Primitive", "size": [2.2, 0.15, 3.2], "offset": [0, 2.5, 0], "color": "roofDark", "id": "roof" }
  ] }
```

### `Model` — модель из папки моделей

JS-модель (`assets/models/<имя>.js`) или модель из Blender (`<имя>.glb`). Как делать модели — [models.md](models.md).

| Свойство | Тип | По умолчанию | Что |
|---|---|---|---|
| `model` | asset | `""` | имя: `"station/lamp-post"`, `"trains/coach-fpk"`, `"spb/station.glb"` |
| `params` | object | `{}` | параметры модели (у каждой свои — см. её файл; неуказанные — по умолчанию) |
| `scale` | number | `1` | масштаб содержимого |

Модели загружаются заранее, при загрузке сцены. Из кода: `await go.getComponent("Model").ready`,
затем `model.meta` (данные модели для логики) и `model.slots("plate")` (меши-слоты для своих текстур).

### `Sprite` — картинка

| Свойство | Тип | По умолчанию | Что |
|---|---|---|---|
| `texture` | asset | `""` | адрес картинки (относительно страницы) |
| `size` | vec2 | `[1, 1]` | ширина и высота, м |
| `color` | color | `"#ffffff"` | цвет-множитель |
| `billboard` | enum | `"camera"` | `camera` — всегда лицом к камере; `vertical` — поворот только вокруг вертикали (деревья, люди); `none` — как объект (вывеска) |
| `glowNight` | number | `0` | подсветка ночью, 0…1 |
| `offset` | vec3 | `[0, 0, 0]` | сдвиг, м |

### `Line` — тонкие линии

Провода, тросы, перила — без мерцания: толщина в метрах, но не тоньше пикселя (тоньше — становится прозрачнее).

| Свойство | Тип | По умолчанию | Что |
|---|---|---|---|
| `points` | array | `[]` | точки ломаной `[[x, y, z], …]` в осях объекта, м |
| `width` | number | `0.015` | толщина, м |
| `color` | color | `"#33373c"` | цвет |
| `sag` | number | `0` | провис между соседними точками, м |
| `closed` | boolean | `false` | замкнуть ломаную |
| `offset` | vec3 | `[0, 0, 0]` | сдвиг, м |

```jsonc
{ "name": "Провод к зданию", "components": [
  { "type": "Line", "points": [[7, 6.2, -40], [-12, 7.5, -48]], "width": 0.012, "sag": 0.4 } ] }
```

### `Glow` — ореол огня

Мягкое пятно, повёрнутое к камере. Свет на поверхности даёт отдельный компонент `Light`.

| Свойство | Тип | По умолчанию | Что |
|---|---|---|---|
| `radius` | number | `1` | радиус, м |
| `color` | color | `"#ffe9c0"` | цвет |
| `intensity` | number | `1` | яркость |
| `night` | boolean | `true` | горит только ночью (и в сумрачную погоду) |
| `offset` | vec3 | `[0, 0, 0]` | где внутри объекта, м |

### Параметры материала

Свойство `material` у `Primitive` (и опция `material` в `kit.box()` и т. п. в моделях). Самое полезное:

| Параметр | Что |
|---|---|
| `glass: true` | стекло: днём отражает небо, ночью светится изнутри; `glassShade: 0…1` — тонировка |
| `emissive: "#…"` | светится всегда |
| `emissiveNight: [r, g, b]` | светится ночью (светильник, окно дома) |
| `litNight: [r, g, b]` | подсветка изнутри ночью, умножается на цвет (табличка с надписью) |
| `toon: true` | гладкое тело в два тона (кроны деревьев) |
| `haze: 0…1` | множитель дымки: меньше — объект виднее вдали |
| `receive: false` | не принимает тени |
| `wet: false` / `snow: false` | не мокнет в дождь / не покрывается снегом |
| `offset: n` | сдвиг глубины — для наклеек, чтобы не мерцали с поверхностью |
| `pattern: {...}` | узор без текстуры и без ряби: `tiles`, `sleepers`, `stripes`, `bars` |
| `transparent`, `opacity` | прозрачность |

Полный список с пояснениями — `ToonOptions` в `engine/render/materials.js`.

## Свет

### `Light` — точечный источник

Пятно света на полу под фонарём, отсвет на борту поезда. Без теней. Учитываются 8 ближайших к камере.

| Свойство | Тип | По умолчанию | Что |
|---|---|---|---|
| `color` | color | `[1, .82, .55]` | цвет (тёплый) |
| `intensity` | number | `1` | яркость |
| `range` | number | `10` | радиус освещения, м |
| `night` | boolean | `true` | горит только ночью (и в сумрачную погоду); `false` — всегда |
| `offset` | vec3 | `[0, 0, 0]` | где источник внутри объекта, м |

### `StripeShadow` — тень решётки узором

Тень ограды на полу считается в шейдере пола — без муара и без карты теней. Плоскость решётки — вдоль
оси `z` объекта (объект не поворачивайте). Не больше двух на сцену.

| Свойство | Тип | По умолчанию | Что |
|---|---|---|---|
| `length` | number | `100` | длина от объекта в сторону −z, м |
| `bottom` / `top` | number | `0.12` / `1.12` | низ и верх прутьев над объектом, м |
| `step` | number | `0.14` | шаг прутьев, м |
| `bar` | number | `0.02` | толщина прута, м |
| `postStep` / `post` | number | `2.5` / `0.06` | шаг и толщина стоек, м |
| `rails` | vec2 | `[1.12, .12]` | высоты двух перил, м |
| `railWidth` | number | `0.05` | толщина перил, м |

## Камеры

### `Camera` — ракурс

Камера — объект. Где стоит и куда смотрит — трансформ объекта (смотрит вдоль своей оси −z)
или `target`. Переключение: `engine.cameras.use("Имя", мс)`, в TrainPaper — панель «Ракурс».

| Свойство | Тип | По умолчанию | Что |
|---|---|---|---|
| `label` | string | `""` | подпись в панели (по умолчанию — имя объекта) |
| `main` | boolean | `false` | камера по умолчанию |
| `target` | vec3 | `null` | точка в мире, куда смотреть, — вместо поворота объекта |
| `focal` | vec2 | `[.6, 1.02]` | фокусное: `f = max(ширина × [0], высота × [1])` пикселей — кадр одинаково собран на любом экране |
| `fov` | number | `0` | или вертикальный угол обзора, ° (0 — по `focal`) |
| `center` | vec2 | `[.5, .5]` | где на экране точка, куда смотрит камера (доли ширины и высоты) |
| `portrait` | object | `null` | поправки для вертикального экрана: `{ "focal": [...], "center": [...] }` |
| `near` / `far` | number | `0.3` / `6000` | ближняя и дальняя плоскости, м |

Как подобрать: откройте `?dev=1`, включите «Свободную камеру», найдите вид (W A S D, Q/E, мышь),
нажмите «Камера в объект» — JSON камеры скопируется, вставьте его в сцену.

### `CameraParallax` — камера за курсором

На объекте с `Camera`: камера слегка поворачивается и сдвигается вслед за курсором.

| Свойство | Тип | По умолчанию | Что |
|---|---|---|---|
| `shift` | vec2 | `[.09, .03]` | сдвиг при курсоре у края экрана `[вбок, вверх]`, м |
| `turn` | vec2 | `[1.4, .75]` | поворот `[по горизонтали, по вертикали]`, ° |
| `ease` | number | `3` | скорость догона курсора (больше — резче) |

## `HtmlScreen`

HTML-элемент страницы, натянутый на прямоугольник в 3D (CSS `matrix3d`). Текст остаётся настоящим
текстом: чёткий при любом ракурсе и дешёвый — 3D-сцену ради него не перерисовывают.
Прямоугольник — в плоскости `xy` объекта, лицом к `+z`. Элемент всегда поверх сцены (его ничто
не заслоняет), поэтому ставьте экран так, чтобы перед ним ничего не было. Отвернулся от камеры — прячется.

| Свойство | Тип | По умолчанию | Что |
|---|---|---|---|
| `element` | string | `""` | CSS-селектор элемента: `"#board"` |
| `size` | vec2 | `[2, 1]` | ширина и высота экрана, м |
| `offset` | vec3 | `[0, 0, .002]` | центр экрана внутри объекта, м |
| `pixelWidth` | number | `1200` | ширина элемента в CSS-пикселях (высота — по пропорции `size`) |

Элемент должен лежать в контейнере движка и иметь `position: absolute; left: 0; top: 0; transform-origin: 0 0`.

## Компоненты TrainPaper

Это компоненты **приложения** (`public/assets/js/platform/components/`), не движка.
Они регистрируются в `main.js` и доступны в сценах TrainPaper.

### `RailTrack` — путь

Путь для поездов: ось — линия вдоль мировой оси `z` через объект. Поезда находят путь по имени объекта.
Внешний вид пути — отдельный `Model` (`station/track`) на том же объекте.

| Свойство | Тип | По умолчанию | Что |
|---|---|---|---|
| `platform` | object | `null` | платформа у пути `{ "top": высота пола, "edge": x края (мир) }` — для света из окон ночью |

### `TrainTraffic` — движение поездов

| Свойство | Тип | По умолчанию | Что |
|---|---|---|---|
| `role` | enum | `"board"` | `board` — поезд с табло РЖД; `passing` — проходящий без остановки |
| `track` | string | `""` | имя объекта-пути (с `RailTrack`) |
| `arrival` | object | `{ heading: 1, stop: { far: -7.2 }, from: 260, ms: 21000 }` | прибытие (`board`) |
| `departure` | object | `{ heading: 1, stop: { far: -7.2 }, ms: 9000 }` | отправление (`board`) |
| `pause` | number | `1800` | пауза между уходом одного поезда и подходом другого, мс |
| `rules` | array | `[]` | свои правила выбора состава для этой сцены (как в `data/trains.jsonc`) |
| `force` | string | `""` | всегда этот состав (предпросмотр; `?train=` в адресе) |
| `train` | string | `"freight"` | состав (`passing`) |
| `heading` | number | `-1` | направление (`passing`): 1 — к камере, −1 — к горизонту |
| `speed` | number | `20` | скорость (`passing`), м/с |
| `every` | vec2 | `[240, 720]` | пауза между поездами (`passing`), с, случайно в диапазоне |
| `first` | number | `40` | через сколько секунд первый поезд (`passing`) |

В `arrival` / `departure`: `heading` — куда смотрит голова (1 — к камере, +z; −1 — к горизонту);
`stop` — `{ "far": z }` дальнего от камеры конца поезда или `{ "near": z }` ближнего; `from` — откуда
начинается подход, м; `to` — куда уходит, м; `ms` — длительность.

### `DepartureBoard` — табло РЖД

Без свойств. Ставится на объект с `HtmlScreen` (префаб `departure-board`) и показывает ближайший
поезд, время, путь, опоздание и бегущую строку.

## Свой компонент

```js
import { Component, registerComponent } from "/engine/index.js";

class Blink extends Component {
  static type = "Blink";                                   // имя в данных: { "type": "Blink" }
  static doc = "Мигает объектом";                          // пояснение в инспекторе
  static props = {
    period: { type: "number", default: 1, min: 0.1, doc: "Период, с" },
    target: { type: "string", default: "", doc: "Имя другого объекта (пусто — этот)" },
  };

  start() {                                                // сцена загружена — можно искать объекты
    const go = this.props.target ? this.engine.find(this.props.target) : this.gameObject;
    this.animate(now => {                                  // 10 раз в секунду, пока компонент жив
      go.object3D.visible = (now / 1000 / this.props.period) % 1 < 0.5;
      this.invalidate();                                   // перерисовать сцену
    }, 10);
  }
  onChange(keys) { /* свойства поменялись через set() или в инспекторе */ }
  onDestroy() { /* animate() останавливается сам; освободите своё */ }
}
registerComponent(Blink);
```

```jsonc
{ "name": "Маячок", "position": [0, 3, -20], "components": [
  { "type": "Primitive", "shape": "sphere", "size": [0.3, 0.3, 0.3], "color": "#ff3524", "material": { "emissive": "#ff3524" } },
  { "type": "Blink", "period": 0.8 } ] }
```

Типы свойств в схеме: `number` (с `min`/`max`), `string`, `boolean`, `color`, `vec2`, `vec3`,
`enum` (с `options`), `array`, `object`, `asset` (имя модели или адрес файла). По ним инспектор
строит поля ввода.

Хорошие привычки:

- внешний вид — через `Model`/`Primitive` на том же объекте, а не геометрией внутри логики;
- данные модели (размеры, точки огней) — из `model.meta`, а не числами в коде;
- никаких своих `requestAnimationFrame`: только `this.animate()` и `this.invalidate()`.

На одном объекте может быть несколько компонентов одного типа (две фигуры, два источника света).
Чтобы префаб мог переопределить конкретный из них, дайте им метку `"id"` в данных; в коде она
доступна как `component.key`.

## Инспектор (`?dev=1`)

Подключается отдельно (`engine/dev/inspector.js`), в обычной работе его кода нет.

- дерево объектов; щелчок — выбрать (объект обводится рамкой);
- трансформ и свойства всех компонентов выбранного объекта — правятся на лету, по схемам `props`;
- «Копировать объект» — JSON выбранного объекта для файла сцены; «Скачать сцену» — вся сцена в `.jsonc`;
- «Свободная камера»: W A S D — вперёд/влево/назад/вправо, Q / E — вниз/вверх, Shift — быстрее,
  мышь с зажатой кнопкой — поворот; «Камера в объект» — текущий вид как объект-камера (JSON);
- «Сетка»: 1 м / 10 м и оси (красная — x, синяя — z);
- счётчики: кадров в секунду по слоям, вызовов отрисовки, треугольников;
- кнопки приложения (в TrainPaper — «Смена поезда», «Транзит»).
