# Железная дорога: пути, поезда, расписание

Модуль приложения `public/assets/js/rail/` (не движка — I1, D7): пути с кривыми, точки остановки, поезд как объект,
движение с торможением к отметке, менеджер поездов, расписание и табло РЖД как его источник.
Подключение — одна строка (компоненты регистрируются): `import "../rail/index.js";`.
Целевая сцена — `assets/scenes/halt.jsonc` («Промежуточная станция», `?scene=halt`).

| Компонент | Что делает |
|---|---|
| `Track` | ось пути: прямые и дуги; `pointAt(s)`, `project(p)`; передаёт ось модели пути |
| `StopPoint` | отметка на пути, чем вставать (голова / хвост / середина), платформа для света из окон |
| `Train` | строит вагоны-объекты по составу; табличка; события `"built"` |
| `TrainMotion` | движение: подход с торможением точно к отметке, стоянка, разгон, проход |
| `TrainLights` | фары у головы, хвостовые огни у хвоста, свет из окон на платформу (`GroundGlow`) |
| `TrainManager` | реестр поездов, появление и уход, очередь на занятый путь |
| `Schedule` | строки расписания → поезда к своему времени по часам симуляции |
| `RzdBoard` | данные онлайн-табло РЖД → строки расписания |
| скрипт `rail/random-traffic` | случайные проходящие поезда |

Координата на пути — `s`, метры вдоль оси от её первой точки; направление `dir`/`direction`: `1` — к росту `s`, `−1` — обратно.

## Путь — `Track`

```jsonc
{ "name": "Путь 1", "position": [4.42, 0, 0], "components": [
  { "type": "Model", "model": "station/track" },
  { "type": "Track", "points": [[0, 0, 300], [0, 0, -400], [-60, 0, -900]], "radius": 800, "visible": [260, 1300] } ] }
```

- `points` — ломаная в осях объекта, углы скругляются дугами `radius` (не хватает прямых — радиус уменьшается).
- Или явные участки от начала объекта к −z: `"segments": [{ "straight": 600 }, { "arc": { "radius": 1200, "angle": 14 } }, { "straight": 2600 }]`
  (`angle > 0` — влево). Параллельные пути на кривой — у соседнего пути радиус больше на расстояние между осями.
- `visible: [s0, s1]` — участок, где поезда видны: менеджер ставит поезд за его краем и убирает, когда поезд
  целиком ушёл за другой край.
- Модель `station/track` на том же объекте получает ось сама (`params.path`) — рельсы лежат по той же кривой,
  по которой едут вагоны. Математика пути — `rail/track-math.js` (без three.js, проверяется тестами).

## Точка остановки — `StopPoint`

```jsonc
{ "name": "Платформа 1", "position": [4.42, 0, -7.2],
  "components": [{ "type": "StopPoint", "track": "Путь 1", "align": "tail",
                   "platform": { "top": 1.1, "edge": 1.92, "side": "left" } }] }
```

- Отметка — `s` или положение объекта (проекция на ось).
- `align`: `"head"` — голова у отметки, `"tail"` — хвост, `"center"` — середина. Поезд любой длины встаёт точно.
- `platform`: `top` — высота пола над головкой рельса, `edge` — от оси пути до края платформы, `side` — с какой стороны
  пути платформа, если смотреть к росту `s`. Нужна для света из окон ночью.

## Поезд — `Train`, `TrainMotion`, `TrainLights`

Префаб `assets/prefabs/train.jsonc` — все три компонента. Поезд можно поставить в сцене:

```jsonc
{ "prefab": "train", "components": [{ "type": "Train", "consist": "fpk-long", "number": "030А" },
                                     { "type": "TrainMotion", "stop": "Платформа 1", "dir": -1 }] }
```

или создать скриптом: `await this.spawn({ prefab: "train", components: [{ type: "Train", consist: "freight", seed: 7 }] })`.

- Состав (`consist`) — имя из каталога `assets/data/trains.jsonc` или список вагонов. Вагон — модель
  (`trains/coach-fpk`, размеры и огни — из её `meta`) или префаб вагона `cars/<имя>` (`assets/prefabs/cars/_template.jsonc`).
- Огни — компоненты `Glow` с метками `head-…`/`tail-…`; `TrainLights` включает фары у головного вагона и хвостовые
  огни у хвостового. Свет из окон на платформу — компонент движка `GroundGlow` на вагонах.
- Табличка — `Train.Plate` (класс задаёт приложение: `platform/plate.js`), данные — `setInfo(info)`.

```js
const m = train.getComponent("TrainMotion");
m.place("Путь 1", 300, -1);           // голова на s = 300, едет к уменьшению s
await m.stopAt("Платформа 1", 40);    // подъехать, встать, стоять 40 с симуляции
await m.depart();                     // разгон и уход за видимый участок
await m.pass(33);                     // проход без остановки со скоростью 33 м/с
// события объекта поезда: "arriving", "arrived", "departed", "left"
```

Параметры `maxSpeed` (м/с), `accel`, `brake` (м/с²). Кривая торможения рассчитана так, чтобы встать точно у отметки
(`rail/kinematics.js`, проверяется тестами). Каждый вагон ставится на путь отдельно — на кривой состав изгибается.
Стоящий поезд — `update` спит, кадров нет.

## Менеджер — `TrainManager`

```js
const m = engine.scene.findComponent("TrainManager");
m.spawn({ id: "6601", consist: "emu-fast", track: "Путь 1", stop: "Платформа 1", action: "stop", dwell: 40, dir: -1 });
m.spawn({ id: "гр-1", consist: "freight", track: "Путь 2", action: "pass", speed: 20, dir: 1, seed: 7 });
m.release("6601");                    // стоящий — отправляется сейчас; ещё в очереди — отменяется
m.updateTrain("6601", { departAt });  // поменять время отправления на ходу
m.list(); m.get("6601");
```

`action`: `"stop"` — подход и стоянка (до `departAt`, `dwell` секунд или пока не отпустят), `"pass"` — проход,
`"stand"` — уже стоит у платформы. На пути — один поезд: следующий ждёт в очереди (`pause` секунд после ухода).
События (на объекте менеджера и `engine.events`): `"trainSpawned"`, `"trainRemoved"`.

## Расписание — `Schedule`

```jsonc
{ "name": "Движение", "components": [
  { "type": "TrainManager" },
  { "type": "Schedule", "rows": [
    { "id": "6601", "consist": "emu-fast", "track": "Путь 1", "stop": "Платформа 1", "action": "stop", "arrive": "14:05", "dwell": 40, "every": 20 },
    { "id": "030А", "consist": "fpk-long", "track": "Путь 1", "action": "pass", "arrive": "14:20", "speed": 33 },
    { "id": "гр-1", "consist": "freight", "track": "Путь 2", "action": "pass", "arrive": "14:32", "speed": 20, "direction": -1 } ] } ] }
```

| Поле строки | |
|---|---|
| `id` | обязательный |
| `number`, `from`, `to` | номер и маршрут (табличка) |
| `consist`, `seed` | состав и зерно смеси вагонов |
| `track`, `stop`, `direction` | путь, точка остановки, направление |
| `action` | `"stop"` или `"pass"` |
| `arrive` | `"ЧЧ:ММ"` (ближайшее), мс или ISO; для прохода — когда поезд проходит остановку или середину видимого участка |
| `depart` / `dwell` | отправление или стоянка, с; `depart: null` — стоять, пока строку не уберут |
| `every` | повтор каждые N минут |
| `speed`, `approach`, `motion` | скорость прохода; за сколько метров до остановки появиться; свои `maxSpeed/accel/brake` |
| `enter` | `"now"` — появиться и подойти сейчас, `"standing"` — уже стоит |

Поезд появляется заранее — на время подхода (рассчитанное той же кинематикой) — и прибывает к своему времени
по часам симуляции. Источники строк: `rows`, файл `src` (JSONC, путь от папки `assets/`, пример —
`assets/data/schedules/example.jsonc`) или поставщик из кода `schedule.setSource(() => rows)`, затем `schedule.refresh()`.
Обновление — сравнение со старым расписанием (`rail/schedule-diff.js`): новая строка — запланировать; удалённая,
но ещё не появившаяся — отменить; поезд уже на сцене — довести и убрать; изменилось время — пересчитать.

## Табло РЖД — `RzdBoard`

```jsonc
{ "type": "RzdBoard", "track": "Путь 1", "motion": { "brake": 1.2, "accel": 0.6 },
  "arrival":   { "stop": "Платформа 1", "direction": -1, "approach": 420 },
  "departure": { "stop": "Отправление", "direction": 1 } }
```

Приложение отдаёт ему текущий поезд табло (`setBoard(current, { instant })`), он превращает его в строку расписания
с `depart: null`: поезд с табло подходит и стоит, пока табло не покажет следующий; тогда текущий уезжает, следующий
подходит. При загрузке страницы поезд уже стоит. Тупиковый вокзал — у отправления своя точка остановки и обратное
направление. Состав — по правилам каталога и своим `rules` сцены, `force` — всегда этот состав (`?train=`).
Табло на платформе (`DepartureBoard`) показывает поезд, который сейчас у платформы (`RzdBoard.shown`).
